# AeroglassWM

A standalone, minimalist Wayland compositor built from scratch in C on **wlroots 0.19** and **SceneFX 0.4**, featuring a diagonal X-cross cursor-aware hybrid tiling grid (**1x1** to **3x2** / **2x3**), sector-based placement, real-time layout HUD, native Kawase blur & window shadows, zero-latency fullscreen for games, Layer-Shell support, and a UNIX-socket IPC CLI (`wmctl`).

**Status:** `v0.2.0-alpha` (Closed-source binary release).

Полную документацию, список зависимостей (`wlroots`, `scenefx`, `cairo` и др.), инструкции по установке через релизы и настройке сессии SDDM/GDM вы можете найти в официальном репозитории на GitHub.
